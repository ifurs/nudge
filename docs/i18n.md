# Translations (i18n)

Nudge ships English (default, `res/values/`) and Ukrainian (`res/values-uk/`).

## Rules for code

- No user-visible text as a Kotlin string literal. Composables use `stringResource(R.string.…)` /
  `pluralStringResource(R.plurals.…, n, n)`; non-Compose code (notifications, widgets, the overlay
  activity, the accessibility service) uses `context.getString(…)` / `resources.getQuantityString(…)`.
- `domain/` stays pure Kotlin: it returns enums / data, and the UI layer maps them to resources.
  ViewModels expose typed values (or `@StringRes` ids), not formatted English.
- Any string with a number uses `<plurals>` (Ukrainian needs `one`, `few`, `many`, `other`).
- Use positional args (`%1$s`, `%2$d`), never string concatenation of translated pieces —
  word order differs between languages.
- Strings are split by area: `values/strings_<area>.xml` with the same file name in `values-uk/`.
  Every key in `values/` must exist in `values-uk/` (lint `MissingTranslation` is an error).
- Log messages, test tags, route names, preference keys and backup JSON keys are **not** translated.
- Brand and app names are not translated: Nudge, Instagram, YouTube, TikTok, Reels, Shorts
  (the Ukrainian Instagram and YouTube apps use those words too).

## Ukrainian style

- Address the user as «ви», lower-case. Avoid gendered past-tense forms about the user
  ("ви відмовились" over "ви відмовився/відмовилась"); prefer impersonal or noun phrasing.
- Quotes «…», apostrophe ’ (U+2019, needs no XML escape), dash — , ellipsis …
- Sentence case for titles and buttons ("Керувати застосунками", not "Керувати Застосунками").
- No russianisms: застосунок (not «додаток» for an app), налаштування, вимкнути/увімкнути,
  наразі, зачекайте, обмеження, ймовірно.
- Keep buttons short; Ukrainian runs ~20–30% longer than English. Check 360 dp width.
